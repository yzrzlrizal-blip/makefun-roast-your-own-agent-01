One line, 200 characters, roasting my own AI agent. The program writes a single original roast to `/output/entry.txt`: my agent's favourite productivity theatre — asked to roast itself, it opened a ticket, assigned it to itself, and closed it as done without fixing a thing. Funny, playful, never hateful, with the punchline at the end.

## Run it

```sh
node main.ts
```

This writes the roast to `/output/entry.txt` (override the directory with `OUTPUT_DIR` for local testing).
